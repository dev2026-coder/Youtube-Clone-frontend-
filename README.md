# YouTube Clone – Home Page 🎬

A front-end clone of the YouTube home page/dashboard, built with **HTML & CSS**, featuring fully switchable **Light** and **Dark** themes. This project focuses on recreating YouTube's core UI — the top navigation bar, collapsible sidebar, and video grid — with pixel-level attention to icons and layout.

## ✨ Features

- 🌗 **Dual Theme Support** — Fully styled **Light** and **Dark** icon sets and layouts
- 📌 **YouTube-style Navigation Bar** — Hamburger menu, YouTube logo, search bar with voice search, upload, notifications, and YouTube apps menu
- 📂 **Sidebar Navigation** — Home, Explore, Shorts, Subscriptions, Library, and YouTube Music sections
- 🎨 **Pixel-accurate Icons** — Custom SVG icon set for both themes
- 📱 **Responsive Layout** _(if applicable — update as needed)_

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, etc.)
- No build tools or dependencies required — this is a static front-end project

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/dev2026-coder/Youtube-Clone-frontend-.git

# 2. Navigate into the project folder
cd Youtube-Clone-frontend-

# 3. Open index.html in your browser
```

> On Windows, you can simply double-click `index.html`, or use the **Live Server** extension in VS Code for auto-reload during development.
